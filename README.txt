校园招聘面试智能分析工具 v1.0
========================================

【 简介 】
本工具帮助面试官在校招初筛阶段，通过 AI 分析候选人对行为面试题的文字回答，
自动评估其"学习能力"和"自驱主动性"，并输出结构化信号报告。


【 快速开始 】

1. 双击 start.bat 启动服务
2. 在浏览器中打开 http://localhost:3000
3. 点击右上角"API 设置"，输入 Anthropic API Key，点击保存
4. 在"面试问题"框中确认或修改问题
5. 将候选人回答粘贴到"候选人回答"文本框
6. 点击"开始分析"，查看分析报告


【 演示功能 】

点击"优秀案例"按钮 → 自动填入高质量候选回答 → 开始分析 → 预期显示"建议直接面试"
点击"普通案例"按钮 → 自动填入普通候选回答 → 开始分析 → 对比两种回答的差异


【 获取 API Key 】

1. 访问 https://open.bigmodel.cn/
2. 注册或登录智谱 AI 账号
3. 进入 API Keys 页面，创建新的 API Key
4. 复制 Key，粘贴到工具的 API 设置中


【 注意事项 】

- API Key 仅保存在浏览器内存中，关闭标签页后自动清除
- 候选人数据仅在本地处理，不会上传至任何第三方服务器
- 分析结果仅供参考，最终面试决策请结合人工判断
- 建议回答长度在 50 字以上，以获得更准确的分析结果
- 按 Ctrl+Enter 可快速触发分析（无需点击按钮）


【 停止服务 】

关闭浏览器页面后，在命令行窗口按 Ctrl+C 停止服务。


【 常见问题 】

Q: 双击 start.bat 闪退？
A: 请确认已安装 Node.js（在命令行输入 node --version 验证）

Q: 提示"无法连接到本地服务器"？
A: 请确认已双击运行 start.bat，看到"服务已启动"提示后再访问页面

Q: 提示"API密钥无效"？
A: 请检查 API Key 是否正确复制（格式：sk-ant-...），且账户余额充足

Q: 分析结果不理想？
A: 可以尝试修改或细化面试问题，或提供更详细的候选人回答

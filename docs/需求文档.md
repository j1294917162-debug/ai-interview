# 需求文档

## 用户原始需求

用户是一位招聘工作者，想要一个 AI 辅助工具，帮助面试官在校招初筛阶段评估候选人的"学习能力"和"自驱主动性"。操作流程：面试官将候选人对某道行为面试题的文字回答粘贴到工具中，工具自动分析并输出结构化信号报告。

### 核心场景

1. **快速筛选**：初筛阶段快速判断候选人质量，减少人工阅读分析时间
2. **现场演示**：通过"优秀案例"和"普通案例"快捷按钮，现场展示 AI 对不同质量回答的判断差异

## 非功能性需求

### 界面风格
- 主色调：淡蓝色（`#4A90D9`）+ 中性灰白背景
- 风格：清爽、专业，适合招聘场景
- 全中文界面

### 性能
- 分析请求超时上限：60秒
- 页面首次加载：< 1秒（无外部依赖）

### 安全
- API Key 仅存储在浏览器 sessionStorage，不落盘
- 所有 API 调用通过本地 localhost 代理转发
- 不上传候选人数据至任何第三方服务器

### 兼容性
- 支持 Chrome、Edge 浏览器
- 桌面端优先（最大宽度 900px 居中布局）
- 最低支持 375px 窄屏（移动端基本可用）

### 可用性
- 无需安装任何依赖（双击 start.bat 即可启动）
- 所有文字使用中文，降低使用门槛

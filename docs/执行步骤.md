## 四、启动与使用

### 启动

1. 双击项目目录中的 `start.bat`
2. 浏览器自动打开 `http://localhost:3000`
3. 点击右上角齿轮图标，粘贴 Anthropic API Key，点击保存

### 使用

1. 在"面试问题"框中确认或修改问题
2. 将候选人回答粘贴到"候选人回答"文本框
3. 点击"开始分析"
4. 查看下方分析报告

### 演示

- 点击"优秀案例"自动填入高质量回答 → 开始分析 → 展示"建议直接面试"结果
- 点击"普通案例"自动填入普通回答 → 开始分析 → 展示对比结果

### 停止

- 关闭浏览器页面
- 在命令行窗口按 `Ctrl+C` 停止服务

## 五、常见问题

| 问题 | 原因 | 解决方法 |
|------|------|----------|
| 双击 start.bat 闪退 | Node.js 未安装或不在 PATH 中 | 安装 Node.js 或检查 PATH |
| 页面显示"无法连接服务器" | server.js 未启动 | 确认已双击运行 start.bat |
| API Key 无效 | Key 错误或已过期 | 检查 Key 格式（`sk-ant-` 开头） |
| 分析结果不理想 | 提示词需要调整 | 联系开发者优化 System Prompt |
